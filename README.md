# ICON

玲娜贝儿与玉桂狗主题策略组图标库。采用透明背景 PNG，适用于 Egern 等支持 JSON 图标集的客户端。

## 图标库

| 图标库 | 数量 | 订阅地址 |
|---|---:|---|
| [玲娜贝儿](LinaBell.json) | 33 款 | [Raw URL](https://raw.githubusercontent.com/BABYANYU/ICON/refs/heads/main/LinaBell.json) |
| [玉桂狗](Cinnamoroll.json) | 13 款 | [Raw URL](https://raw.githubusercontent.com/BABYANYU/ICON/refs/heads/main/Cinnamoroll.json) |

## 添加方式

复制所需图标库的 **Raw URL 链接地址**，在客户端的图标集管理中通过 URL 添加并保存。加载完成后，即可为策略组选择图标。
